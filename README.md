# deepseek-proxy

DeepSeek API 代理服务。

## 快速开始

```bash
# 安装依赖
npm install

# 启动服务
npm start
```

## 分支策略

本项目采用简化版 Git Flow，详见 [CONTRIBUTING.md](./CONTRIBUTING.md)。

- `main` — 生产就绪代码
- `develop` — 开发集成分支
- `feature/*` / `fix/*` / `hotfix/*` — 临时工作分支
